# Data Model: Mini Issue Tracker

**Branch**: `001-mini-issue-tracker` | **Date**: 2026-08-14

Phase 1 output for [plan.md](plan.md). Derives the entity model from
[spec.md](spec.md). Storage is SQLite via Drizzle ORM (see
[research.md](research.md)); this document is storage-agnostic in structure.

## Entities

### User

Represents an account that signs in and belongs to workspaces.

| Field | Type | Rules |
|-------|------|-------|
| id | UUID | Primary key |
| email | string | Unique, normalized lowercase, valid email format |
| passwordHash | string | Argon2id hash; never stored in plaintext |
| createdAt | timestamp | Set on creation |
| updatedAt | timestamp | Updated on changes |

Relationships: owns 0..n Workspaces (as owner), member of 0..n Workspaces
(via Membership), assignee of 0..n Issues, author of 0..n Comments.

### Workspace

A team container holding projects.

| Field | Type | Rules |
|-------|------|-------|
| id | UUID | Primary key |
| name | string | Required, non-empty, trimmed; unique per owner |
| ownerId | UUID | FK → User.id; the creator/owner |
| createdAt | timestamp | Set on creation |
| updatedAt | timestamp | Updated on changes |

Relationships: has 1 owner (User), 0..n members (via Membership), 0..n
Projects.

Validation: name required, not blank; duplicate name for the same owner is
rejected (edge case).

### Membership

Join table linking a User to a Workspace.

| Field | Type | Rules |
|-------|------|-------|
| userId | UUID | FK → User.id; part of composite PK |
| workspaceId | UUID | FK → Workspace.id; part of composite PK |
| joinedAt | timestamp | Set when joining |

Relationships: many-to-many between User and Workspace. The owner is
implicitly a member (ownerId on Workspace).

### Invitation

A one-time join token generated by the owner for an existing user.

| Field | Type | Rules |
|-------|------|-------|
| id | UUID | Primary key |
| workspaceId | UUID | FK → Workspace.id |
| token | string | High-entropy, single-use, hashed at rest |
| expiresAt | timestamp | Required; invitation is invalid after this time |
| usedAt | timestamp | Null until the invitation is redeemed |
| createdAt | timestamp | Set on creation |

Relationships: belongs to 1 Workspace.

Validation: token single-use (usedAt set on redeem); expired invitations
(expiresAt < now) are rejected (FR-005, edge case).

### Project

A container for issues within a workspace.

| Field | Type | Rules |
|-------|------|-------|
| id | UUID | Primary key |
| workspaceId | UUID | FK → Workspace.id |
| name | string | Required, non-empty, trimmed |
| createdAt | timestamp | Set on creation |
| updatedAt | timestamp | Updated on changes |

Relationships: belongs to 1 Workspace; contains 0..n Issues.

### Issue

A tracked work item.

| Field | Type | Rules |
|-------|------|-------|
| id | UUID | Primary key |
| projectId | UUID | FK → Project.id |
| title | string | Required, non-empty, trimmed |
| description | string | Optional, free text |
| status | enum | Open, In Progress, Closed (clarified) |
| priority | enum | Low, Medium, High, Urgent (clarified) |
| assigneeId | UUID | Nullable FK → User.id; must be a member of the issue's workspace |
| dueDate | date | Nullable; may be in the past (edge case) |
| createdAt | timestamp | Set on creation |
| updatedAt | timestamp | Updated on changes |

Relationships: belongs to 1 Project; assignee is 1 User (optional); has 0..n
Comments; tagged with 0..n Labels (via IssueLabel).

Validation: title required (FR-013); assignee restricted to workspace members
(edge case); status/priority constrained to the clarified enum values.

### Comment

A text note attached to an issue.

| Field | Type | Rules |
|-------|------|-------|
| id | UUID | Primary key |
| issueId | UUID | FK → Issue.id |
| authorId | UUID | FK → User.id |
| body | string | Required, non-empty |
| createdAt | timestamp | Set on creation |

Relationships: belongs to 1 Issue; authored by 1 User.

### Label

A short tag applied to issues for grouping and filtering.

| Field | Type | Rules |
|-------|------|-------|
| id | UUID | Primary key |
| workspaceId | UUID | FK → Workspace.id (labels are workspace-scoped) |
| name | string | Required, unique within the workspace |

Relationships: workspace-scoped; applied to issues via IssueLabel.

### IssueLabel

Join table linking Issues to Labels.

| Field | Type | Rules |
|-------|------|-------|
| issueId | UUID | FK → Issue.id; part of composite PK |
| labelId | UUID | FK → Label.id; part of composite PK |

## State Transitions

Issue status transitions (clarified values):

- `Open` → `In Progress` → `Closed`
- `Open` → `Closed` (allowed directly)
- `In Progress` → `Open` (re-open)
- `Closed` → `Open` (re-open)
- No other transitions are defined in this version.

## Relationships Overview

```text
User ──owner──> Workspace ──< Membership >── User
Workspace ──< Project ──< Issue ──< Comment (author: User)
Project ──< Issue ──< IssueLabel >── Label (workspace-scoped)
Issue.assigneeId ──> User (must be a workspace member)
Workspace ──< Invitation
```

## Validation Rules Summary

- User email: required, unique, normalized, valid format.
- Workspace name: required, non-empty, unique per owner.
- Project name: required, non-empty.
- Issue title: required, non-empty.
- Issue status: one of Open / In Progress / Closed.
- Issue priority: one of Low / Medium / High / Urgent.
- Comment body: required, non-empty.
- Invitation token: single-use, expires after `expiresAt`.
- Assignee: must belong to the issue's workspace membership.
- Deletions of projects and issues require user confirmation (FR-014) at the
  UI layer; deleting a project cascades to its issues.

## Scale Assumptions

- ~25 members per workspace, ~1,000 issues per project, ~10 workspaces per
  user. All columns used in filters (status, priority, assigneeId) and search
  (title, description) are candidates for indexing at implementation time.
